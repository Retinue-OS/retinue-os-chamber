This is a static, read-only mirror of the live Retinue dashboard UI. It reproduces the interface — the same stylesheet, cards and layout as the real Progressive Web App — over content committed to this repository. It is not connected to any live system: there are no conversations, no message composer, no voice input and no way to act on anything shown. Nothing on this page reads or writes personal data. Source and issues: github.com/retinue-os.
